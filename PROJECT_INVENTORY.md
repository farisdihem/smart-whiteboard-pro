# PROJECT INVENTORY

- **Project Name:** Interactive Whiteboard
- **Project Type:** Web / Desktop Application
- **Language:** JavaScript, HTML, CSS, Rust
- **Framework:** Vanilla JS + Vite + Tauri
- **Version:** 3.5.0
- **Entry Point:** index.html / app.js
- **Build System:** Vite & Cargo (Tauri)
- **Dependencies:** Firebase, html2canvas, jsPDF, KaTeX, Lucide
- **Main Features:** Interactive Canvas, Educational Modules (Math, Geography, Biology), Media Recorder, WebRTC, Multi-page support
- **Database:** Firebase Firestore
- **External Services:** Firebase
- **Build Commands:** `npm run build`, `npm run tauri build`
- **Run Commands:** `npm run dev`, `npm run tauri dev`
- **Test Commands:** `node test_video_forensic.js`, `node full_forensic_suite.js`
- **Environment Variables:** Firebase config json
- **Deployment Method:** Vercel/Netlify for web, Github Releases for Tauri binaries
